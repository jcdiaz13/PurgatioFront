## Sobre el Proyecto

[![Product Name Screen Shot][product-screenshot]](https://example.com)

Purgatio es un juego para 3 a 8 personas en el que los jugadores confiesan sus pecados y reciben castigos basados en las votaciones de los demás. Desarrollado como un proyecto colaborativo por un equipo de 5 personas.
